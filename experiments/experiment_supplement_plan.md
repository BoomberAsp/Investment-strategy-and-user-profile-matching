# 实验 B.1：用户-策略匹配验证

**优先级**：P0
**日期**：2026-07-04

---

## 论证链

```
实验一（已完成）──→ 同类型投资者在特征空间中聚在一起      (用户 ↔ 用户, 合成数据)
     +
实验 B.1 ────────→ 用户与适合他的策略在特征空间中靠近      (用户 ↔ 策略, 合成伪标签)
     ↓
完整论证：统一特征空间 + 空间中的距离反映真实匹配关系 = 有效
```

论证逻辑：实验一已证明特征提取函数 `f(交易记录) → R¹²` 能赋予度量空间以行为区分力——交易行为相似的实体在特征空间中靠近。由于用户和策略走的是**完全相同的 `f`**（`pipeline.py` 中 `extract_user_behavior_features` 等函数对两者无差别调用），这一性质的对称性在数学上是成立的，不需要在策略侧单独验证。

**真正缺失的一环是跨实体对齐**：即便用户和策略在空间中各自成簇，也不能自动推出"相容用户离源策略最近"。B.1 填补的正是这一点。

---

## 1. 核心挑战与应对

**挑战**：没有真实的用户-策略匹配标注数据。

**应对**：从真实策略的交易记录出发，通过多层次的交易记录层面扰动生成"相容用户"，构造伪标签。关键设计原则：

1. **扰动在交易记录层面，不在特征空间层面** —— 避免循环论证（用度量空间定义标签，再用标签验证度量）
2. **噪声幅度从真实账户校准** —— 不凭空设定，用 3 个真实账户的 Bootstrap 方差做参考
3. **评估聚焦排序而非二分类** —— Pairwise ranking 比"匹配/不匹配"二分类更贴近推荐场景
4. **构造困难负样本** —— 测试度量在模糊边界上的区分力，而非仅测试"完全不同"的容易场景

---

## 2. 方法总览

```
Phase 1: 策略行为画像提取
  37 个策略 → 12 维特征向量 s_1, ..., s_37

Phase 2: 噪声幅度校准
  3 个真实账户 → 账户内交易记录的 Bootstrap 方差 → σ_calibrated

Phase 3: 相容用户生成
  对每个策略 k:
    策略 k 的交易记录 → Resample + Perturb → 20 个"相容用户"的交易记录
    → 12 维特征提取 → u_{k,1}, ..., u_{k,20}
    标签: y(u_{k,i}, 策略 k) = 正匹配

Phase 4: 困难负样本构造
  选择 10 对"部分行为相似但关键维度不同"的策略对
  对每对中的相容用户，将另一个策略作为困难负样本

Phase 5: 排序评估
  Pairwise Ranking Accuracy, Top-N Recall, MRR
  在对抗性子集上单独报告
```

## 3. Phase 1：策略行为画像提取

**输入**：37 个策略的清洗后交易记录（`DLMethod/clean_strategies.csv`）

**处理**：

```
For 每个策略 k (k = 1 to 37):
  1. 加载策略 k 的所有交易记录
  2. 调用 pipeline.py 特征提取函数:
     - extract_user_behavior_features(trades)
     - extract_user_asset_pref_features(trades)
     - extract_user_risk_proxy_features(trades)
  3. 得到 12 维特征向量 s_k
  4. 记录: 策略名称, 策略 ID, s_k, 总交易笔数, 交易时间跨度
```

**产出**：`strategy_features.csv`（37 × 12），可直接复用 `pipeline.py` 的已有输出。

**关键检查**：确保与项目代码使用**完全相同的**特征提取函数（`pipeline.py` 中的 `MATCH_FEATURES`、`extract_user_behavior_features` 等）。记录每个策略的交易笔数分布（均值、方差），用于评估后续用户生成是否引入了不合理的数据量偏差。

## 4. Phase 2：噪声幅度校准

### 4.1 设计动机

扰动幅度不能凭空设定。太小的噪声 → 用户几乎是策略的完美副本 → 任何度量都能匹配正确（天花板效应）。太大的噪声 → 用户行为面目全非 → 任何度量都匹配失败（地板效应）。

需要在合理范围内校准噪声幅度。3 个真实账户虽然不足以做训练或统计推断，但足以做**噪声幅度的经验参考**。

### 4.2 校准方法（主方案：账户内 Bootstrap 方差）

```
For 每个真实账户 a ∈ {Account_A, Account_B, Account_C}:
  For b = 1 to 100:
    从账户 a 的交易记录中有放回抽样 80% 的交易 → 子样本 b
    从子样本 b 提取 12 维特征 → f_{a,b}
  计算 σ_a[d] = std(f_{a,1}, ..., f_{a,100})  对每个特征维度 d

校准后的扰动幅度:
  σ_calibrated[d] = median(σ_A[d], σ_B[d], σ_C[d])  对每个特征维度 d
```

**备选方案（策略间方差作为上界）**：

```
σ_strategy[d] = std(s_1[d], ..., s_37[d])  (37 个策略在维度 d 上的标准差)
σ_calibrated[d] = min(σ_bootstrap[d], σ_strategy[d] × 0.20)
  → 取两者中较小值，保证扰动幅度不超出合理范围
```

### 4.3 敏感性分析

对校准后的 σ 设置 3 个缩放级别，测试结论对噪声幅度的敏感性：

| 缩放级别 | 倍数 | 含义 |
|---------|------|------|
| 低噪声 | 0.5 × σ_calibrated | 用户与策略行为非常接近 |
| 中噪声 | 1.0 × σ_calibrated | 校准后的基准水平 |
| 高噪声 | 2.0 × σ_calibrated | 用户与策略有较大行为差异 |

## 5. Phase 3：相容用户生成

### 5.1 设计原则

**不在特征空间加噪声**，而是在交易记录层面做扰动。因果链为：交易记录 → 特征提取（含固有噪声）→ 特征向量。这保证了扰动的来源（交易层面）与待验证度量的作用域（特征空间）之间有一层噪声隔离。

### 5.2 扰动操作

对策略 k 的交易记录施加多层独立扰动，每次扰动生成一个"相容用户"：

**操作 1：Bootstrap 重采样**

```
从策略 k 的交易记录中有放回抽样，样本量 = 原始交易数的 85%-95%
→ 模拟用户相对于策略的"不完整观察"（真实世界中总有数据缺失）
```

**操作 2：交易金额微调**

```
每笔交易的 amount 乘以 exp(N(0, 0.15²))
→ 模拟同一行为风格下不同资金规模的个体差异
（保持 BUY/SELL 比例不变，仅调整规模）
```

**操作 3：交易时间微调**

```
每笔交易的日期偏移 N(0, 2²) 个交易日（四舍五入）
→ 模拟交易节奏的微小个体差异
（不影响持有时长，因为买卖日期同时偏移）
```

**操作 4：少量随机交易插入**

```
以 5%-10% 的概率插入额外交易:
  - 随机在策略持仓池中选股
  - 随机 BUY/SELL
  - 金额 = 策略平均交易金额 × exp(N(0, 0.3²))
→ 模拟个体投资者的"噪音交易"（与策略风格无关的随机行为）
```

**操作 5：随机交易删除**

```
随机删除 3%-8% 的交易记录
→ 模拟数据缺失
```

### 5.3 生成流程

```
For 每个策略 k (k = 1 to 37):
  For i = 1 to 20:  (每策略生成 20 个相容用户)

    trades_k = 策略 k 的原始交易记录

    操作1: trades' ← BootstrapResample(trades_k, ratio=0.90)
    操作2: trades' ← PerturbAmount(trades', σ_amount=0.15)
    操作3: trades' ← PerturbDate(trades', σ_date=2)
    操作4: trades' ← InsertNoiseTrades(trades', prob=0.08)
    操作5: trades' ← RandomDrop(trades', prob=0.05)

    u_{k,i} ← ExtractFeatures(trades')  (12 维特征向量)
    
    标签: y(u_{k,i}, s_k) = 1 (正匹配)

  → 37 × 20 = 740 个合成用户
```

### 5.4 合理性验证

生成后，检查相容用户的特征分布是否合理：

```
For 每个策略 k:
  计算 20 个相容用户的特征向量均值 μ_k_users
  计算 ‖μ_k_users - s_k‖  (用户均值与策略的距离)
  
  预期: 用户均值应接近原策略（距离 < 2 × σ_calibrated 的模长）
  
  若某些策略的用户均值远离原策略:
    → 该策略的交易记录可能有特殊性（如交易太少）
    → 标记为需人工审查，或在分析中分层报告
```

## 6. Phase 4：困难负样本构造

### 6.1 设计动机

普通负样本（随机选一个不同策略）太容易区分。真正的挑战在于：**当一个策略与用户的"相容策略"在部分维度上相似时，度量能否做出正确判断？**

这正是径向惩罚的理论优势场景——方向相似但模长不同时，模长惩罚能否纠正方向上的混淆。

### 6.2 构造方法

**Step 1：策略对筛选**

在 37 个策略中，用 12 维特征的余弦相似度和模长比筛选策略对：

```
For 每对策略 (A, B):

  cos_sim = cosine(s_A, s_B)     # 方向相似度
  norm_ratio = ‖s_A‖ / ‖s_B‖    # 模长比

  "方向相似但模长不同" 的选择标准:
    cos_sim > 0.7   AND   norm_ratio > 1.5 (或 < 0.67)
  
  → 标记为"困难对"
```

选取 10 对满足条件的策略对。

**Step 2：对抗性测试集**

```
For 每对 (策略A, 策略B):
  用户群 A: 从策略 A 生成的 20 个相容用户
  用户群 B: 从策略 B 生成的 20 个相容用户

  对用户群 A 中的每个用户 u:
    正匹配: 策略 A
    困难负样本: 策略 B  (cos_sim 高但模长差异大)
    普通负样本: 从剩余 35 个策略中随机采样 5 个

  → 对抗性子集: 10 对 × 20 用户 × (1 正样本 + 1 困难负 + 5 普通负)
```

**预期**：纯余弦容易在困难对上犯错（方向相似 → 给策略 B 高分）；径向惩罚通过模长差异纠正这一错误 → 在困难对上准确率更高。这是评估径向惩罚**可分解性优势**的关键场景。

## 7. Phase 5：评估

### 7.1 指标定义

**Pairwise Ranking Accuracy (PRA)**：

对每个用户 u（由策略 k 生成），取一个负样本策略 j ≠ k，评估：

```
PRA = P( sim(u, s_k) > sim(u, s_j) )  对所有 (u, j≠k) 对

具体计算:
  correct = 0; total = 0
  For 每个正样本用户 u (由策略 k 生成):
    For 每个负样本策略 j (j ≠ k):
      If sim(u, s_k) > sim(u, s_j): correct += 1
      total += 1
  PRA = correct / total
```

随机基线 = 0.5。

**Top-N Recall (Recall@N)**：

```
Recall@N = 正匹配策略在 Top-N 推荐中的比例

即: 对用户 u (由策略 k 生成)，在所有 37 个策略中按相似度排序，
策略 k 排在前 N 名的比例。
```

随机基线 = N / 37（N=1: 2.7%, N=3: 8.1%, N=5: 13.5%）。

**Mean Reciprocal Rank (MRR)**：

```
MRR = mean( 1 / rank(正匹配策略) )  对所有用户

rank ∈ {1, 2, ..., 37}，rank=1 最佳。
```

随机基线 = (1 + 1/2 + ... + 1/37) / 37 ≈ 0.11。

**全量评估**（740 用户 × 37 策略）：

| 纯余弦 | | | | | |

| 径向惩罚 λ=0.75 | | | | | |
| 径向惩罚 λ=1.0 | | | | | |

**对抗性子集**（10 对策略，仅含正样本 + 困难负样本 + 普通负样本）：

| 度量 | PRA (全量) | PRA (困难负) | PRA (普通负) |
|------|-----------|-------------|-------------|
| 纯余弦 | | | |

### 7.3 噪声敏感性分析

对每个噪声级别（0.5× / 1.0× / 2.0× σ_calibrated），重复 Phase 3-5：

| 噪声级别 | 度量 | PRA | Recall@3 | MRR |
|---------|------|-----|----------|-----|
| 0.5× | 径向 λ=1.0 | | | |
| 1.0× | 径向 λ=1.0 | | | |
| 2.0× | 径向 λ=1.0 | | | |

预期：随着噪声增大，所有度量的性能下降，但径向惩罚在困难负样本上的相对优势可能更明显。

### 7.4 统计检验

- **McNemar 检验**：径向惩罚 vs 纯余弦在 PRA 上的配对差异是否显著
- **Bootstrap 置信区间**（1000 次重采样用户）：MRR 和 Recall@N 的 95% CI
- **分层分析**：按生成策略的交易笔数分组（≤100, 101-500, >500），报告各组性能
